#1 BMC Firmware
AMI · v12.4 · 4 nodes
CRITICAL 69.6/100
Known vulnerabilities
  • CVE-2023-34329 REAL CRITICAL · CVSS 9.1
    Authentication bypass via HTTP header spoofing in AMI MegaRAC BMC's Redfish host interface. Part of the 'BMC&C' vulnerability set disclosed by Eclypsium; affects devices from AMD, Asus, Dell EMC, Gigabyte, HPE, Lenovo, Nvidia, and others using MegaRAC SP-X. — source
  • CVE-2023-34330 REAL HIGH · CVSS 8.2
    Code injection via AMI MegaRAC's Dynamic Redfish Extension interface, allowing arbitrary code execution as root on the BMC chip. Chains with CVE-2023-34329 for full remote takeover. — source
Lifecycle flags
  • Component reached end-of-life on 2024-06-30 - no further security patches expected.
  • 'BMC Firmware' is flagged as a single-source dependency - no qualified alternate vendor on record.
Recommended actionPatch/upgrade BMC Firmware (AMI) past the affected version range, or isolate on a management-only network segment until patched.
